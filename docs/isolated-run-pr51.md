- T1：`google` / `maps`
- T2：`facebook` / `cpc`
- T3：官網在旗標關閉時送出的那筆「沒有來源欄」的真實 POST

最接近的只有腳本自己的案例，不能拿來代替：

- 案例 1 是腳本省略 9 個來源欄，格子空白。這不是瀏覽器送出的。
- 案例 2、3 是 `google` / `cpc`，不是 `google` / `maps`。
- 案例 4 是腳本寫入 `direct/unknown`，不是「旗標關閉、欄位根本沒送」。

這次能證明的：這份 1415 行腳本在隔離表上會收這 8 筆、電話留著開頭 0、人數和日期不是文字、公式開頭以文字留下、重複編號不新增也不再寄信、14 封都進測試信箱、客人信沒有活動代碼。
